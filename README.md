# Лабораторные по «Экспертным системам» — вариант 5

Все 8 лабораторных работ (лаб.5 и лаб.6 выполняются вместе, как требует
задание) реализованы на **Visual Prolog** (диалект PDC Prolog / Turbo
Prolog — тот самый, что описан в методичке: разделы `domains`,
`predicates`, `clauses`, `goal`).

Компилятор и линковщик лежат прямо в этом проекте (`tools/vip`) —
устанавливать ничего не нужно, всё уже готово к работе через
командную строку.

## Как запустить любую лабораторную (через командную строку)

Ничего ставить не нужно — компилятор уже в `tools/vip`. Достаточно:

1. Открыть **cmd.exe** (командная строка Windows) или **PowerShell**.
2. Перейти в папку нужной лабы, например:
   ```
   cd /d E:\ES2026_Labs_Variant5\labs\lab1
   ```
3. Запустить:
   ```
   run.bat
   ```

`run.bat` сам:
   - скомпилирует `.PRO`-файл компилятором `PRO.EXE`,
   - слинкует получившийся `.OBJ` в `.exe` линковщиком `pdclink.exe`,
   - сразу запустит готовую программу.

Если что-то в коде поменяли — просто запустите `run.bat` ещё раз,
он пересоберёт программу заново.

Если вместо этого нужна ПОЛНАЯ графическая среда разработки (как в
методичке — с меню Project/Application Expert и т.д.), в
`tools\vip\BIN\WIN\32\vip.exe` лежит родная IDE Visual Prolog. Но для
самих лабораторных это не обязательно — достаточно `run.bat`.

## Что сделано в каждой лабораторной (вариант 5)

### Лаб.1 — основы Пролога (`labs/lab1`)
**Файл:** `LAB1.PRO`.
База данных `raspol(Предприятие,Страна)` + `postav(Кто,Кому,Товар,Сумма)`.
Два запроса:
  1. по стране и минимальной сумме — список всех товаров, которые
     какое-либо предприятие этой страны поставляет за рубеж;
  2. по предприятию и сумме — что оно закупает за границей.
Работа организована циклом (`repeat`, определённый вручную — в этом
диалекте Пролога `repeat` не встроен, п.1.6.2 методички) с вопросом
«Продолжить работу?» после каждого запроса.
**Изучается:** факты/правила, откат через `fail` для перебора всех
ответов, отсечение `!`, организация повторяющегося диалога.

### Лаб.2 — списки и рекурсия (`labs/lab2`)
**Файл:** `LAB2.PRO`.
1. Расщепление списка чисел на первые N элементов и остаток
   (рекурсия по списку, разбор на голову/хвост `[H|T]`).
2. `raspol(Страна,СписокПредприятий)` + `postav(...)` — по стране и
   сумме выводится список товаров, экспортируемых предприятиями этой
   страны (через предикат `prinadl` — проверка принадлежности списку).
**Изучается:** домены-списки, рекурсивная обработка списков,
использование списков как значений в базе фактов.

### Лаб.3 — базы данных на Прологе (`labs/lab3`)
**Файлы:** `LAB3.PRO`, `lab3.dba` (сама база данных отдельным файлом).
`contr(Шифр,Покупатель,Товар,Оплата)` — Оплата это **альтернативный
домен**: `opl(Сумма)` (оплачено полностью) или `predopl(С1,С2)`
(предоплата + доплата). `pokup(Предприятие,Страна,Город)`.
Меню: загрузка БД (`consult`), просмотр списка контрактов, добавление
нового покупателя (`assert`), сохранение БД (`save`), выход.
**Изучается:** функторы и альтернативные домены, файловые базы данных
(`consult`/`save`/`assert`/`retract`), меню на `repeat`.

### Лаб.4 — логические функции (`labs/lab4`)
**Файл:** `LAB4.PRO`.
Задача про неисправности A,B,C,D сложного устройства. Условия из
задания переведены в алгебраическую форму (по таблицам из методички:
дизъюнкция = `A+B-A*B`, импликация `X->Y` = `Y-X>=0` и т.д.), затем
программа перебирает все 16 комбинаций 0/1 и печатает те, что
удовлетворяют всем условиям сразу.
**Изучается:** представление логических высказываний в
алгебраической форме, полный перебор (generate-and-test) на Прологе.

### Лаб.5-6 — продукционная ЭС + механизм вывода (`labs/lab5_6`)
**Файлы:** `LAB5_6.PRO`, `volkan.dba` (база знаний отдельным файлом).
Экспертная система «угроза извержения вулкана»: правила вида
`rule(Номер, [условия], assign(Переменная,Значение))`, целевая
переменная `D` (рекомендуемые действия), обратный логический вывод
(`obr_vyvod`/`proverka`/`prov1` — в точности по методичке).
**Специфика варианта 5 (то, что отличает эту лабу от примера в
книге):** пункт меню **«4 - как»** — подсистема объяснений: печатает
список ВСЕХ переменных базы знаний, пользователь выбирает одну, и
программа рекурсивно объясняет, по какому правилу и на основе каких
данных было получено её значение (либо что оно введено пользователем
напрямую).
**Изучается:** продукционные правила, обратный вывод, подсистема
объяснений ЭС.

### Лаб.7 — распознавание образов (`labs/lab7`)
**Файл:** `LAB7.PRO`.
Диагностика неисправностей ЛЭП (Н1/Н2/Н3) по концентрации ацетилена и
углеводородов. Программа:
  1. считает решающие функции на основе **минимального расстояния**
     (прототип каждого класса = среднее по обучающей выборке);
  2. распознаёт новый объект (24,18) этими функциями;
  3. строит **разделяющие решающие функции по алгоритму восприятия**
     для всех трёх пар классов (пара 1-2 ещё и посчитана вручную в
     комментарии в начале файла — сверьте с тем, что выведет
     программа, коэффициенты должны совпасть);
  4. распознаёт тот же объект разделяющими функциями.
**Изучается:** решающие функции, алгоритм восприятия (перцептрон),
геометрическая интерпретация распознавания образов.

### Лаб.8 — байесовская оценка (`labs/lab8`)
**Файл:** `LAB8.PRO`.
Медицинская ЭС выбора лекарства: по статистике (300 больных, признаки
температура/боль/отклонения в крови) считается апостериорная
вероятность улучшения по формуле Байеса — пошагово, с печатью каждой
промежуточной величины (априорные вероятности, условные вероятности
признаков, формула умножения, сама формула Байеса).
**Изучается:** теорема Байеса, оценка достоверности вывода ЭС на
основе статистики.

## Важное примечание об исходном задании

В комментариях в начале каждого `.PRO`-файла приведена точная
формулировка задания варианта 5, а также (где это уместно) ручной
расчёт контрольного примера — чтобы вы могли сверить с тем, что
выводит программа, и без проблем перенести решение в отчёт.

Все программы были реально скомпилированы, слинкованы и запущены
(через `tools\vip`) для проверки — вывод каждой соответствует ручным
расчётам, приведённым в комментариях.
